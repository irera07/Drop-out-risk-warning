How to use EduGuard — step by step
1

Upload your class file

Go to Daily Checking. Click the upload zone and select a CSV or Excel file containing your student data. The columns must match the features your ML model was trained on (e.g. attendance, grades, family info).

2

Review and edit the student table

After uploading, your class list appears in an editable table. Click any cell to correct a value. When done, click Save changes — this stores a new version of the file.

3

Add individual students

Use the Add single student button to open a form and add a new learner to the existing class list. They will appear in the table immediately.

4

Generate a dropout risk report

Go to Current Report and click Check updated report. The system merges all file versions (weighting the most recent at 70%) and runs the ML model. This may take a few seconds.

5

Interpret the results

The report shows each student's dropout prediction, risk level (High / Medium / Low), and the probability score. Click ▾ Reason to expand a student's row for more detail. Download the full table as CSV using the download button.

6

Access historical reports

Every generated report is saved automatically. Go to Previous Reports to view past predictions — filtered to your class — and download any of them as CSV.
